

### 🌐 Global App Navigation
These shortcuts work anywhere in the main application window to help you jump around instantly.

| Shortcut | Action |
| :--- | :--- |
| **`Ctrl + F`** | **Smart Search Focus:** Automatically targets the search bar of the tab you are currently viewing. |
| **`Ctrl + Tab`** | Go to the next tab. |
| **`Ctrl + Shift + Tab`** | Go to the previous tab. |
| **`Ctrl + 1` to `8`** | Instantly jump to a specific tab (e.g., `Ctrl+1` for Dashboard, `Ctrl+8` for Timeline). |
| **`Ctrl + M`** | **Restore Background Players:** Brings any media players you sent to the background back to the front. |
| **`Ctrl + T`** | Toggle Dark / Light Theme. |
| **`F5`** | Global Refresh (Reloads database, repopulates all trees and tables). |
| **`Ctrl + Q`** | Quit the application. |

### 🎬 The Viewer (Universal)
These commands work anytime you have a file open in the Dedicated Viewer, regardless of what type of file it is.

| Shortcut | Action |
| :--- | :--- |
| **`PageDown`** | **Force Next File:** Absolute command to jump to the next file in the playlist. |
| **`PageUp`** | **Force Prev File:** Absolute command to jump to the previous file in the playlist. |
| **`F11`** | Toggle Fullscreen mode. |
| **`Esc`** | Exit Fullscreen (if active) OR Close the viewer window. |
| **`H`** | **Zen Mode:** Hides/Unhides the bottom navigation bar and all media controls. |
| **`B`** | **Background Mode:** Hides the viewer window completely so you can keep listening to audio while browsing the main app. |

---

### 🖼️ Dedicated Image Viewer
These shortcuts activate dynamically when you are viewing images (`.jpg`, `.png`, etc.).

| Shortcut | Action |
| :--- | :--- |
| **`Right Arrow`** | Next Image. |
| **`Left Arrow`** | Previous Image. |
| **`Ctrl + Scroll`** | Zoom In / Zoom Out smoothly. |
| **`+` or `=`** | Zoom In. |
| **`-`** | Zoom Out. |
| **`0`** | **Fit to Screen:** Instantly resets zoom and centers the image. |
| **`R`** | Rotate image 90 degrees clockwise. |
| **`F`** | Flip image horizontally (Mirror). |
| **`Shift + F`** | Flip image vertically. |
| **`S`** | **Slideshow:** Toggles the animated auto-play slideshow. |
| **`Click & Drag`** | Pan around the image when zoomed in. |

### 🎵 Dedicated Media Player (Audio & Video)
These shortcuts activate dynamically when you are playing video or audio files.

| Shortcut | Action |
| :--- | :--- |
| **`Spacebar`** | Play / Pause. |
| **`Right Arrow`** | Next Media File. |
| **`Left Arrow`** | Previous Media File. |
| **`Shift + Right Arrow`**| **Seek Forward:** Jumps ahead 5 seconds. |
| **`Shift + Left Arrow`** | **Seek Backward:** Jumps back 5 seconds. |
| **`Up Arrow`** | Volume Up (+10%). |
| **`Down Arrow`** | Volume Down (-10%). |
| **`M`** | Mute / Unmute audio. |

---

### ⭐ MySpace Sandbox
These shortcuts are mapped directly to the table in the Sandbox tab for rapid file organization.

| Shortcut | Action |
| :--- | :--- |
| **`Ctrl + C`** | **Copy:** Marks selected items (and their virtual contents) to be copied. |
| **`Ctrl + X`** | **Cut:** Marks selected items to be moved. |
| **`Ctrl + V`** | **Paste:** Pastes copied/cut items into the currently viewed virtual folder. |
| **`Delete`** | Removes selected items from the Sandbox (does *not* delete the real files on your disk). |

---

### 📅 Timeline Diary
We mapped these specifically to override default table behaviors so you can browse your history smoothly.

| Shortcut | Action |
| :--- | :--- |
| **`Enter` / `Return`** | Opens the currently highlighted file in the Pro Viewer (or opens the folder). |
| **`Backspace`** | Clears the specific daily date filter and loads the full timeline limit (up to 25,000 recent events). |
| **`Up / Down Arrows`** | Natively scrolls through the timeline table. |
